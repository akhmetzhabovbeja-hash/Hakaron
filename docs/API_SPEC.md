## Общая информация

| Параметр | Значение |
|---|---|
| Протокол | HTTP/HTTPS |
| Формат данных | JSON |
| Кодировка | UTF-8 |
| Backend базовый URL | `http://localhost:8000/api/v1` |
| ML Service базовый URL | `http://localhost:8001/api/v1` |

### Роли пользователей

| Роль | Описание |
|---|---|
| `candidate` | Кандидат -- заполняет анкеты |
| `manager` | Менеджер -- просматривает и оценивает кандидатов |
| `hr` | HR-специалист -- работает с одобренными кандидатами |

### Формат ошибки

Все ошибки возвращаются в едином формате:

```json
{
  "detail": "Описание ошибки"
}
```

---

## Аутентификация

Большинство эндпоинтов требуют JWT-токен в заголовке:

```
Authorization: Bearer <access_token>
```

Токены получаются через `/auth/register` или `/auth/login`. Поле `token_type` всегда равно `"bearer"`.

### Auth -- Авторизация

---

#### POST /auth/register

Регистрация нового пользователя в системе.

| Параметр | Значение |
|---|---|
| Метод | `POST` |
| Путь | `/api/v1/auth/register` |
| Доступ | Публичный |
| Авторизация | Не требуется |

**Тело запроса:**

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `email` | `string` | Да | Email пользователя |
| `name` | `string` | Да | Имя пользователя |
| `password` | `string` | Да | Пароль (мин. 8 символов) |
| `role` | `string` | Да | Роль: `candidate`, `manager`, `hr` |

**Тело ответа (200):**

| Поле | Тип | Описание |
|---|---|---|
| `access_token` | `string` | JWT access-токен |
| `refresh_token` | `string` | JWT refresh-токен |
| `token_type` | `string` | Тип токена (`"bearer"`) |

**Коды ответов:**

| Код | Описание |
|---|---|
| 200 | Успешная регистрация |
| 400 | Некорректные данные (невалидный email, слабый пароль, недопустимая роль) |
| 409 | Пользователь с таким email уже существует |
| 500 | Внутренняя ошибка сервера |

**Пример запроса:**

```http
POST /api/v1/auth/register
Content-Type: application/json

{
  "email": "ivanov@example.com",
  "name": "Иван Иванов",
  "password": "securePass123",
  "role": "candidate"
}
```

**Пример ответа:**

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

#### POST /candidates/submit-questionnaire

Отправка заполненной анкеты кандидатом. После отправки запускается AI-анализ ответов.

| Параметр | Значение |
|---|---|
| Метод | `POST` |
| Путь | `/api/v1/candidates/submit-questionnaire` |
| Доступ | `candidate` |
| Авторизация | `Bearer <access_token>` |

**Тело запроса:**

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `vacancy_id` | `integer` | Да | ID вакансии |
| `full_name` | `string` | Да | ФИО кандидата |
| `email` | `string` | Да | Email кандидата |
| `phone` | `string` | Да | Телефон кандидата |
| `answers` | `array[Answer]` | Да | Массив ответов на вопросы |

**Объект Answer:**

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `question_number` | `integer` | Да | Номер вопроса |
| `question_text` | `string` | Да | Текст вопроса |
| `answer_text` | `string` | Да | Текст ответа кандидата |

**Тело ответа (200):**

| Поле | Тип | Описание |
|---|---|---|
| `message` | `string` | Сообщение об успешной отправке |
| `candidate_id` | `integer` | ID созданной записи кандидата |

**Коды ответов:**

| Код | Описание |
|---|---|
| 200 | Анкета успешно отправлена |
| 400 | Некорректные данные (пустые ответы, невалидный email/телефон) |
| 401 | Не авторизован |
| 403 | Недостаточно прав (не роль `candidate`) |
| 404 | Вакансия с указанным `vacancy_id` не найдена |
| 500 | Внутренняя ошибка сервера |

**Пример запроса:**

```http
POST /api/v1/candidates/submit-questionnaire
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
Content-Type: application/json

{
  "vacancy_id": 1,
  "full_name": "Иван Иванов",
  "email": "ivanov@example.com",
  "phone": "+7-999-123-45-67",
  "answers": [
    {
      "question_number": 1,
      "question_text": "Расскажите о вашем опыте работы с Python",
      "answer_text": "Работаю с Python 5 лет, опыт в FastAPI, Django, Flask. Разрабатывал микросервисные архитектуры."
    },
    {
      "question_number": 2,
      "question_text": "Какие ваши сильные стороны?",
      "answer_text": "Быстрая обучаемость, аналитическое мышление, опыт работы в команде."
    }
  ]
}
```

**Пример ответа:**

```json
{
  "message": "Анкета успешно отправлена",
  "candidate_id": 42
}
```

## Диаграмма взаимодействия сервисов

```
Клиент (браузер)
    |
    | HTTP запросы
    v
Backend API (порт 8000)
    |
    | Внутренний вызов POST /api/v1/analyze
    v
ML Service (порт 8001)
    |
    | AI-анализ ответов
    v
Результат анализа -> Backend -> Клиент
```

### Жизненный цикл кандидата

```
1. Кандидат заполняет анкету       -> POST /candidates/submit-questionnaire
2. Backend отправляет на анализ    -> POST /analyze (ML Service)
3. Менеджер просматривает список   -> GET /manager/candidates
4. Менеджер смотрит анализ         -> GET /manager/candidates/{id}/analysis
5. Менеджер одобряет/отклоняет     -> POST /manager/candidates/{id}/approve
6. HR видит одобренных             -> GET /hr/approved
7. HR отправляет уведомление       -> POST /hr/notify/{id}
```

### Статусы кандидата

| Статус | Описание |
|---|---|
| `pending` | Анкета отправлена, ожидает анализа |
| `analyzed` | AI-анализ завершен, ожидает решения менеджера |
| `approved` | Одобрен менеджером, передан в HR |
| `rejected` | Отклонен менеджером |
| `notified` | HR отправил уведомление кандидату |
